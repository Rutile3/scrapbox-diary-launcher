# Scrapbox Diary Launcher

旧 `RedirectPage` は `scrapbox-diary-launcher` へ改名され、日付ベースのScrapbox日記ページを扱う統合ランチャーになりました。

現在の基本的な使用方法は、リポジトリの[README](../../README.md)を参照してください。旧URLからの更新については[移行ガイド](../MIGRATION.md)に記載しています。

## Scrapbox日記機能

- [CreateToday](./CreateToday.md)
- [ShowToday](./ShowToday.md)
- [CreateMonthSchedule](./CreateMonthSchedule.md)
- [ShowMonthSchedule](./ShowMonthSchedule.md)

## 旧RedirectPage版の記録

> GitHub Pagesで静的サイトを公開し、JavaScriptで特定のページにリダイレクトするページ群。

初回移行時のホームには、CreateMonthSchedule、ShowMonthSchedule、ShowTodayへのリンクが掲載されていました。CreateTodayと使用素材はページとして存在しましたが、ホームからはリンクされていませんでした。
