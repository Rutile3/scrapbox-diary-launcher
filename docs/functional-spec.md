# 機能仕様書

## 1. 文書の目的

この文書は、Scrapbox Diary Launcherの現行機能と外部動作を定義する仕様書です。実装変更時は、ソースコード、テスト、この文書の内容を一致させます。

利用手順は [README](../README.md)、旧RedirectPageからの更新方法は[移行ガイド](./MIGRATION.md)を参照してください。

## 2. システム概要

本システムは、日付ベースのScrapboxページを開くための静的なGitHub Pagesアプリケーションです。次の機能を提供します。

- 正規ランチャーURLを解釈し、対象のScrapboxページへ遷移する
- 月間予定ページの本文をブラウザー内で生成する
- 正規URL、ブックマークレット、Scrapbox UserScript、PowerShell、BATを画面から生成する
- 改名後のリポジトリ内で、従来の4つのHTMLパスと旧パラメーターを正規ランチャーへ変換する

プレーンなHTML、CSS、JavaScriptで動作し、フレームワーク、外部CDN、ビルド処理、実行時サーバーを必要としません。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 正規ランチャー | リポジトリのルートページと現行パラメーターで構成するインターフェース |
| 互換エンドポイント | 従来のHTMLパスとパラメーターを正規ランチャーへ変換する入口 |
| 対象日 | 日次ページ名の生成に使用するローカル日付 |
| 対象月 | 月次ページ名および月間予定本文の生成に使用するローカル月 |
| 本文 | Scrapboxのページ作成URLへ `body` として渡す文字列 |

## 4. 正規ランチャー

### 4.1 ベースURL

```text
https://rutile3.github.io/scrapbox-diary-launcher/
```

クエリ文字列もURLフラグメントもない場合は遷移を行わず、ランチャージェネレーターと利用案内を表示します。

### 4.2 共通パラメーター

| 名前 | 指定場所 | 必須 | 形式と動作 |
| --- | --- | --- | --- |
| `action` | クエリ | 必須 | 4.3に記載する4値のいずれか |
| `project` | クエリ | 必須 | 4.4の検証を満たすScrapboxプロジェクト名 |
| `date` | クエリ | 任意 | 日次アクションで使用する厳密な `YYYY-MM-DD` |
| `month` | クエリ | 任意 | 月次アクションで使用する厳密な `YYYY-MM` |
| `body` | フラグメント | 任意 | `create-today` だけで使用する自由記述本文 |

`date` または `month` を省略した場合は、ブラウザーの現在日時をローカル時刻として使用します。空文字列は省略とは扱わず、不正な形式として扱います。

正規ランチャーは、選択されたアクションで使用しない `date` または `month` を参照しません。ジェネレーター画面では、誤指定を防ぐためアクションと一致しない組み合わせを生成しません。

### 4.3 アクション

#### `show-today`

- 対象日を `date` または現在のローカル日付から決定する
- `YYMMDD` 形式の日次ページ名を生成する
- 本文を付けず、対象のScrapboxページへ遷移する

#### `create-today`

- 対象日を `date` または現在のローカル日付から決定する
- `YYMMDD` 形式の日次ページ名を生成する
- URLフラグメントに `body` がある場合、本文付きScrapbox URLへ遷移する
- `body` がない場合、本文クエリを付けずにページへ遷移する

#### `show-month`

- 対象月を `month` または現在のローカル月から決定する
- `YYMM` 形式の月次ページ名を生成する
- 本文を付けず、対象のScrapboxページへ遷移する

#### `create-month-schedule`

- 対象月を `month` または現在のローカル月から決定する
- `YYMM` 形式の月次ページ名を生成する
- 6.に定義する月間予定本文を生成する
- 本文付きScrapbox URLへ遷移する

### 4.4 プロジェクト名の検証

`project` は次の条件をすべて満たす必要があります。

- 文字列である
- 空文字列でない
- 前後に空白がない
- `/`、`\\`、`?`、`#`、制御文字を含まない

プロジェクト名はURLのパス要素としてURLエンコードします。日本語および文字列内部の空白は使用できます。

### 4.5 本文の受け渡し

本文は次の形式でURLフラグメントへ指定します。

```text
?action=create-today&project=Example#body=ENCODED_TEXT
```

- フラグメントは `URLSearchParams` として解析する
- `body` の値は最終的なScrapbox URLでUTF-8のURLエンコードを行う
- 日本語、空白、改行、`&`、`%`、`#`、`?`、`=`、引用符を扱える
- クエリ文字列に `body` がある場合は、アクションにかかわらずエラーにする
- `create-today` 以外でフラグメントの `body` が指定された場合はエラーにする

本文はGitHub PagesへのHTTPリクエストに含まれません。ただし、最終的な遷移先であるScrapboxにはページ作成用クエリとして送信されます。

### 4.6 遷移先URL

日次ページ:

```text
https://scrapbox.io/<URLエンコード済みproject>/<YYMMDD>
```

月次ページ:

```text
https://scrapbox.io/<URLエンコード済みproject>/<YYMM>
```

本文が指定されたページ:

```text
https://scrapbox.io/<URLエンコード済みproject>/<ページ名>?body=<URLエンコード済み本文>
```

## 5. 日付処理

### 5.1 正規形式

- 日付は `YYYY-MM-DD` の固定桁数で指定する
- 月は `YYYY-MM` の固定桁数で指定する
- 存在しない日付または月を拒否する
- JavaScriptの自動的な日付繰り上げは許容しない

### 5.2 ページ名

- 日次ページ名は年の下2桁、月2桁、日2桁を連結した `YYMMDD`
- 月次ページ名は年の下2桁と月2桁を連結した `YYMM`

例:

| 入力 | ページ名 |
| --- | --- |
| `2024-02-29` | `240229` |
| `2026-09-10` | `260910` |
| `2024-12` | `2412` |

## 6. 月間予定本文

`create-month-schedule` は、対象月について次の本文を生成します。

```text
[**** [前月YYMM]←→[翌月YYMM]]

[*** YYYY年MM月]
[YYMM01] 曜 
[YYMM02] 曜 
...

[**** [前月YYMM]←→[翌月YYMM]]

#月予定表
```

- 月の全日を1日から月末まで昇順で出力する
- 曜日はローカル日付に基づき、`日`、`月`、`火`、`水`、`木`、`金`、`土` の1文字で出力する
- 各日付行の曜日の後ろには半角空白を1文字置く
- 前月および翌月は年境界をまたいで計算する
- 本文末尾には改行を置く

## 7. エラー仕様

正規ランチャーで検出する主なエラーは次のとおりです。

| コード | 条件 |
| --- | --- |
| `invalid-url` | 入力URLを解析できない |
| `missing-action` | パラメーターを含むURLで `action` がない |
| `invalid-action` | 未対応の `action` が指定された |
| `body-in-query` | クエリ文字列に `body` が指定された |
| `body-not-supported` | `create-today` 以外でフラグメントの `body` が指定された |
| `invalid-parameter` | `project`、`date`、`month` または日付計算が不正 |

エラー発生時はScrapboxへ遷移せず、利用者が原因を確認できる日本語メッセージを画面へ表示します。エラーメッセージへ本文を出力しません。

## 8. ランチャージェネレーター

### 8.1 入力画面

パラメーターのないルートページで次を入力できます。

- Scrapboxプロジェクト名
- アクション
- 日次アクション用の日付
- 月次アクション用の月
- `create-today` 用の本文

アクションに応じて使用可能な入力欄を切り替えます。入力変更後は以前の生成結果を非表示にし、再生成が必要であることを通知します。

### 8.2 入力の組み合わせ

- 日次アクションに `month` は指定できない
- 月次アクションに `date` は指定できない
- `create-today` 以外に `body` は指定できない
- 指定された日付、月、プロジェクト名は正規ランチャーと同じ規則で検証する

### 8.3 出力

1回の生成操作で次の5形式を出力します。

| 出力 | 形式 |
| --- | --- |
| 正規ランチャーURL | 検証済みの入力を含む絶対URL |
| ブックマークレット | 正規URLへ遷移する `javascript:void(location.href=...)` 形式のJavaScript URL |
| Scrapbox UserScript／JavaScript | `location.href` に正規URLを代入する即時実行関数 |
| PowerShell | `Start-Process -FilePath '<正規URL>'` |
| BAT | `@start "" "<正規URL>"` |

PowerShellでは単一引用符を2個に、BATでは `%` を `%%`、二重引用符を2個にしてエスケープします。

### 8.4 コピー

- 各出力にコピーボタンを設ける
- セキュアコンテキストではClipboard APIを使用する
- Clipboard APIを使用できない場合は、選択範囲と `document.execCommand("copy")` を使用する
- 成功または失敗を画面上のステータスとして通知する
- 失敗時は対象テキストを選択し、手動コピーを可能にする

## 9. 互換エンドポイント

### 9.1 対象パス

改名後のリポジトリ内で次のパスを維持します。

```text
Scrapbox/Diary/CreateToday/CreateToday.html
Scrapbox/Diary/ShowToday/ShowToday.html
Scrapbox/Diary/CreateMonthSchedule/CreateMonthSchedule.html
Scrapbox/Diary/ShowMonthSchedule/ShowMonthSchedule.html
```

各HTMLは共有の互換変換処理を読み込み、正規ランチャーURLへ置換遷移します。

### 9.2 パラメーター変換

| 旧パラメーター | 正規パラメーター | 変換 |
| --- | --- | --- |
| `project_url` | `project` | 値をそのまま引き渡す |
| `yymmdd` | `date` | `YYMMDD` を2000年代の `YYYY-MM-DD` へ変換する |
| `yymm` | `month` | `YYMM` を2000年代の `YYYY-MM` へ変換する |
| `body` | フラグメントの `body` | `CreateToday`だけでクエリからフラグメントへ移す |

互換エンドポイントに限り、`project_url` がない場合は従来の既定値 `Rutile3-Test` を使用します。正規ランチャーにはこの既定値を適用しません。

不正な `yymmdd` または `yymm` は、旧実装との互換性を維持するため変換先から省略し、正規ランチャーに現在のローカル日付または月を使用させます。

### 9.3 互換範囲

互換エンドポイントが保証するのは、新しい `/scrapbox-diary-launcher/` 配下のパスだけです。旧 `/RedirectPage/` を含むGitHub Pages URLの転送は保証しません。

## 10. セキュリティと保存

- 自由記述本文をGitHub Pagesへのクエリ文字列に含めない
- 本文をコンソールへ出力しない
- 入力値や本文を `localStorage` または `sessionStorage` へ保存しない
- 不正な入力で別のScrapboxプロジェクトへ暗黙に転送しない
- ユーザー入力はURL、ブックマークレット、JavaScript、PowerShell、BATの用途に応じてエンコードまたはエスケープする

## 11. 対応範囲外

- Scrapboxの認証または権限管理
- Scrapboxページの作成完了確認
- サーバー側での本文保存または中継
- 旧 `/RedirectPage/` Pages URLの自動転送
- 汎用的なScrapbox自動化機能

## 12. 検証

自動テストでは次を確認します。

- 有効・無効な日付、うるう日、月境界、年境界
- 日次・月次ページ名とScrapbox URL
- 月間予定本文
- 4アクションとエラー条件
- 本文のフラグメント受け渡しと特殊文字
- 互換パラメーター変換
- ブックマークレット、UserScript、PowerShell、BAT生成
- 画面に必要な入力、出力、コピー操作
- 文書間リンク

ブラウザー操作など、自動化だけで完結しない確認は[手動確認手順](./MANUAL_TESTS.md)に記録します。
